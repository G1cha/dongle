# Dongle

Личный финансовый помощник для жизни во Вьетнаме: расходы в VND с отображением в RUB, кошельки в нескольких валютах, месячные отчёты и лимиты по категориям.

## Возможности

- расходы с автоматической или ручной датой;
- пересчёт VND → RUB по ежедневному курсу и сохранение курса каждой операции;
- отчёты за день, 7 дней и месяц;
- круговая диаграмма расходов по категориям;
- месячные лимиты в VND или RUB с автоматическим пересчётом и предупреждениями при достижении 80% и 100%;
- кошельки в VND, RUB, USD и USDT;
- автоматическое списание из выбранного кошелька и возврат при удалении расхода;
- экспорт и импорт резервной копии в JSON;
- адаптивный интерфейс для телефона и компьютера.

При первом запуске доступны два кошелька: наличные донги и наличные доллары. Остальные можно добавить с главной страницы или в разделе «Кошельки». Ранее сохранённый набор кошельков не меняется.

Данные хранятся только в `localStorage` браузера. Сайт не отправляет финансовую историю на сервер. Курс берётся из открытого [Currency API](https://github.com/fawazahmed0/exchange-api) через основной и резервный адреса и обновляется раз в день. При недоступности сети используется последний сохранённый курс; при самом первом запуске без сети показывается помеченный как примерный резервный курс.

## Локальный запуск

Это статическое приложение без сборки и зависимостей:

```bash
python3 -m http.server 4173
```

После запуска откройте `http://localhost:4173`.

## Публикация на GitHub Pages

Для ручной загрузки распакуйте `GitHub_Pages_Upload.zip` и перетащите **его содержимое** в корень репозитория через **Add file → Upload files**. Не загружайте сам ZIP: GitHub Pages нужны файлы `index.html`, `app.js`, `styles.css`, `icon.svg`, `README.md` и `.nojekyll` в корне репозитория. На macOS скрытый `.nojekyll` можно показать в Finder сочетанием `⌘⇧.`.

Затем откройте **Settings → Pages → Build and deployment** и выберите **Deploy from a branch → main → / (root)**, после чего нажмите **Save**. Сайт появится по адресу, который GitHub покажет в разделе Pages.

Если загружаете проект через Git с сохранением `.github/workflows/pages.yml`, можно вместо этого выбрать **GitHub Actions** как источник публикации.

> Важно: данные разных браузеров и устройств не синхронизируются. Для переноса используйте экспорт и импорт в настройках приложения.
